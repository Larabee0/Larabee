This was myself and Ethan Moorfield's Final Major Project from college - this is a online multiplayer free for all Spaceship fighting game.

The spaceships where made out of parts that could be destroyed and would fall off. The game ended when one player was left.

This would have been heavily inspired by War Thunder, it mimics the control scheme and over engineered damage model. Although quite impressive technically, the code isn't amazing and is quite specialised to the Unity Netcode API circa 2022.
It was basically nailed together in 7 weeks.
