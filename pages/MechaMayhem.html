MechaMayhem is a 2-4 player local-pvp style game much like wii tanks. This game was made by a first year team of 8 students + an extra for propmotional art.

The university brief for the project set a number of constraits such as having native controller support, take no longer than 10 minutes to play, and it had to include at least one of six "diversifiers".

These diversifiers were;
1. Support 2 player local co-op
2. Fit into one screen (fixed camera)
3. Contain historically accurate information about a local place or subject
4. present educational information suitable for use with a musem or local attractrion.
5. Be a digital version of a game which is ususally a physical, for example a computerised version of a TTRP or card game. 6. Include alternative physical input devices/copntrollers and/or control external devices (such as lights or other hardware)

We ended up implementing 1, 2 and 6. With the sixth being the result of me finding a wii remote api for C#/unity on github then adding wiimote support to the game one evening just because I thought it was funny.

After proving it worked and everyone else on the team also thought it was funny/cool I wrote a much more refined implementation, a custom device for the modern Unity Input System - the code for which can be browsed in the project repo linked above.

For this game I built all the UI code behind, the controller system for switching between controllers, the powers, the mechs themselves, loading between levels. The other programmers worked on the map gimmicks like the lava rising on the volcano.
