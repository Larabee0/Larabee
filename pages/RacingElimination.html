This was a second year college project made in the first term under a game-jam theme of "One More-Go". Myself and an 3d Artist, Ethan Moorfield, co-developed this mario kart like racing game which every so often eliminated last place until there was one kart left - the winner.

This is single player and uses Unity's ML-Agents for the computer players controls, the game has a catch-up system were those further back in the pack go faster than those at the front.

Althought very simple the game ended up being a lot of fun to develop and play and I am tempted to go back and expand on it with multiplayer functionality and navmesh karts instead of ML ones.

This is the first game I had a part in with a full game life cycle title screen & end screen or any UI to be honest. The karts supported keyboard and Xbox Controller controls, I also deployed the game to the launch model Xbox One Console the College had access to.

Editor Tool

The most notable code thing I made for this was a very simple editor tool to automate placement of check points used for tracking the poll position of the karts as shown above. 

            
            using System.Collections;
            using System.Collections.Generic;
            using UnityEngine;
            using PathCreation;
            
            public class TrackToCheckPoint : MonoBehaviour
            {
                public PathCreator path;
                [Range(1, 50)]
                public float resolution = 1;
            
                public CheckPoint trackerPrefab;

                public void PlaceCheckPoints()
                {
                    float length = path.path.length;
                    for (float i = 0; i < length; i += resolution)
                    {
                        Vector3 point = path.path.GetPointAtDistance(i);
                        Vector3 dir = point - path.path.GetPointAtDistance(i + resolution);
                        Spawn(point, dir);
                    }
                }
            
                private void Spawn(Vector3 Pos, Vector3 forward)
                {
                    CheckPoint tracker = Instantiate(trackerPrefab, Pos, Quaternion.identity, transform);
                    tracker.transform.forward = forward;
                }
            }
