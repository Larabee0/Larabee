Favourite Projects

Vulkan ECS Game Engine (VECS)

Crowning achievemnt of my university work is a Enity Component System (ECS) game engine built in C# using Vulkan, Vulkan Memory Allocator and SDL3

It has an in-frame compute shader pipeline which is used for GPU culling, Shader Reflection, Assimp mesh loading, Free Image image loading, automatic mipmap generation and many other things besides.

Since university I have added BepuPhysics, a physics engine library to it making it offically a game engine (Graphics + Physics) and more recently I have added NOESIS GUI and started working on building a GUI editor for the engine.

Disseration Project

Wide analysis of QSlim Applied to Generated Convex Terrain

My Disseration project from my 3rd year of university compared a mesh optimisation algorithm called QSlim against running a noise map based terrain generator.

The project compared the accuray of the optimised mesh to a very high sample rate generated mesh - this high sample rate mesh is composed of millions of vertices and is very unoptimised. QSlim's goal is to min-max geometry to shape accuracy using geometric deviation anaylsis. I compared it to the terrain generator configured to the same number of triangles as QSlim to see which was better able to represent the shape.

The research showed that QSlim could be used to very effectively reduce the geometry of these terrain meshes while maintaining high shape accuracy as compared to the terrain generator at teh same number of triangles.

This would allow savings in GPU memory for the mesh data and time to draw, with minimal sacrifcy to visual quality. However, in real time applications it may be impratical as the implementation of QSlim I used could take multiple minutes to optimise a mesh. Multi-threaded and Compute shader implementations of QSlim exist that are able to optimise a mesh in real time however.
