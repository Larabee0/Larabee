Favourite Projects

Vulkan ECS Game Engine (VECS)

Crowning achievemnt of my university work is a Enity Component System (ECS) game engine built in C# using Vulkan, Vulkan Memory Allocator and SDL3

It has an in-frame compute shader pipeline which is used for GPU culling, Shader Reflection, Assimp mesh loading, Free Image image loading, automatic mipmap generation and many other things besides.

Since university I have added BepuPhysics engine library to it making it offically a game eninge and more recently I have added UltraLight a WebView Based GPU accelerated Html renderer.

TTRPG & Foundry VTT System based on RimWorld

Personal project since 2021 a TTRPG system based on RimWorld, implemented in Foundry VTT

The public repo contains the Foundry module, which is all web-dev JS stuff

Nerfgun Game Controller

Indivual project from 1st year of uni where we had to make a physical game controller and a game built around it.

For this I reverse engineered a nerfgun and turned into a motion controller for aiming a gun in a mobile game where you shoot random targets in a shooting range.
